# Euclid Q1 Morphology Consistency Audit: Methods and Results (v0.1.0)

**Author**: Biswajit Jana

## Abstract

We audit consistency between real Euclid Quick Release 1 (Q1) galaxy
morphology measurements: VIS-band vs. NIR-band single-Sersic index fits,
and the parametric Sersic index vs. the independently computed
non-parametric CAS concentration statistic, for the same real objects, all
queried live from the public IRSA TAP service. On 20,000 real,
quality-flagged Q1 objects, VIS-NIR Sersic index shows no population-level
bias but weak per-object correlation (Pearson r=0.20); Sersic index and
CAS concentration show a moderate positive correlation (Spearman r=0.41).
A live, catalog-wide query found the official Q1 catalog's two-component
bulge+disk Sersic fit is entirely unpopulated (NULL for all 29,953,430
rows), a genuine finding that changed this project's planned cross-method
comparison. This project audits official-pipeline outputs; it performs no
independent re-measurement and makes no claim about which of two
disagreeing measurements is more accurate.

## 1. Introduction

Euclid Q1 (released 2025-03-19) is the mission's first public data
release, and its morphology catalog will be used by many downstream
studies. Understanding where its measurements agree or disagree across
filters and methods is directly useful groundwork for anyone building on
it. This project is a companion to this author's `euclid-star-shapes`
(PSF/astrometry) and `euclid-spectra-quality` (spectral contamination)
audits, covering the distinct question of extended-source morphology
consistency.

## 4. Results

All numbers below are read from `results/default/`, generated by

|---|---|---|

## 5. What this result does and does not show

This demonstrates that (a) VIS and NIR Sersic-index measurements for the
same galaxy are not systematically offset from each other but do disagree
substantially on a per-object basis, and (b) two conceptually related but
methodologically distinct morphology statistics track each other only
moderately. It does **not** determine which measurement is more accurate
for any given object, does not cover the disk+bulge fit (unpopulated in
this release), and does not yet properly resolve sky-position dependence
(the default sample is spatially concentrated -- `docs/LIMITATIONS.md`).
