# Euclid Q1 Morphology Measurement Comparison: Methods and Results (v0.2.0)

**Author**: Biswajit Jana

## Abstract

We compare real Euclid Quick Release 1 (Q1) galaxy morphology
measurements: VIS-band vs. NIR-band single-Sersic index fits, and the
parametric Sersic index vs. the independently computed non-parametric CAS
concentration statistic, for the same real objects, all queried live from
the public IRSA TAP service, stratified across the three real Q1 deep
fields. On 20,000 real, quality-flagged Q1 objects, VIS-NIR Sersic index
shows a statistically significant but practically negligible
population-level bias (median diff -0.00158, 95% bootstrap CI
[-0.00317, -0.00078], Wilcoxon p=2.9e-13) -- about 460x smaller than the
per-object scatter (MAD=0.731) -- and weak per-object correlation (Pearson
r=0.198); Sersic index and CAS concentration show a moderate positive
correlation (Spearman r=0.428). A live, catalog-wide query found the
official Q1 catalog's two-component bulge+disk Sersic fit is entirely
unpopulated (NULL for all 29,953,430 rows), a genuine finding that changed
this project's planned cross-method comparison. Binning residuals within
each deep field's own footprint (rather than the combined range of all
three, which collapsed the check to one bin per field) recovers real
sub-field spatial resolution. This project compares official-pipeline
outputs; it performs no independent re-measurement and makes no claim
about which of two disagreeing measurements is more accurate.

## 1. Introduction

Euclid Q1 (released 2025-03-19) is the mission's first public data
release, and its morphology catalog will be used by many downstream
studies. Understanding where its measurements agree or disagree across
filters and methods is directly useful groundwork for anyone building on
it. This project is a companion to this author's `euclid-star-shapes`
(PSF/astrometry) and `euclid-spectra-quality` (spectral contamination)
audits, covering the distinct question of extended-source morphology
consistency.

## 5. What this result does and does not show

This demonstrates that (a) VIS and NIR Sersic-index measurements for the
same galaxy carry a population-level bias that is statistically
significant but two to three orders of magnitude smaller than the
per-object scatter -- practically negligible for most uses, though a
reader with a use case sensitive to a ~0.002-level systematic should not
round it to exactly zero -- and (b) two conceptually related but
methodologically distinct morphology statistics track each other only
moderately. It does **not** determine which measurement is more accurate
for any given object, and does not cover the disk+bulge fit (unpopulated
in this release). Binning within each deep field's own footprint recovers
real sub-field spatial resolution (19 populated bins, `docs/METHODS.md`),
but each field's own cone-search radius is still narrow, so this remains
a modest, not fine-grained, spatial-systematics check
(`docs/LIMITATIONS.md`).
