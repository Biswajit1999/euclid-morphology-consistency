## Data and context

- All morphology measurements analyzed are real Euclid Quick Release 1
  (Q1) MER catalog values, queried live from the NASA/IPAC Infrared
  Science Archive (IRSA) TAP service. This project performs no
  measurement of its own -- it audits consistency between measurements
  the official Euclid pipeline already produced.
- This project is a companion to, and does not duplicate, this author's
  `euclid-star-shapes` (point-source PSF/astrometry audit) and
  `euclid-spectra-quality` (NISP spectral-contamination audit)
  repositories; each covers a distinct aspect of Q1 data-quality
  assessment.
- This project is an independent audit and is not an official Euclid
  Consortium, ESA, or IRSA product, and is not affiliated with or
  endorsed by those organizations.
